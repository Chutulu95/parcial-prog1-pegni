# NotaFácil

Programa de consola en Python para gestionar las notas de un curso
(Primer Parcial de Programación I).

## Qué hace

Carga alumnos con dos notas cada uno y, desde un menú, permite ver el
listado con promedios, estadísticas del curso, un ranking ordenado por
promedio, buscar un alumno por nombre y jugar con los nombres cargados.

## Cómo ejecutarlo

```
python main.py
```

## Módulos

- `main.py`: menú principal.
- `validaciones.py`: validación de cantidad, notas y nombres.
- `procesamiento.py`: cálculos, ordenamiento, búsqueda y presentación.
